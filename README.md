## Zermat

I'm an entomologist working on Italian ants (Formicidae) and ground beetles
(Carabidae). My username is an ant: *Camponotus vagus*.

Most of what's here started as a tool I needed for my own specimens, photos or
data. When it seemed useful to others, I cleaned it up and published it.

I write most of the code with Claude, Anthropic's AI assistant. What each tool
should do, the testing on real specimens and data, and the decision to publish
are mine.

### Entomology

- [formiche-ditalia](https://github.com/Camponotus-vagus/formiche-ditalia): interactive key to the ant genera of Italy, live at [formicheditalia.it](https://www.formicheditalia.it)
- [entomology-labels](https://github.com/Camponotus-vagus/entomology-labels): printable specimen labels, including straight from geotagged field photos
- [iNaturalist-Image-Downloader](https://github.com/Camponotus-vagus/iNaturalist-Image-Downloader): batch image downloads from iNaturalist observations, for ML datasets
- [gbif-downloader](https://github.com/Camponotus-vagus/gbif-downloader) and [nebria_downloader_v2](https://github.com/Camponotus-vagus/nebria_downloader_v2): download and filter GBIF occurrence records

### Imaging and 3D

- [StackAnt](https://github.com/Camponotus-vagus/StackAnt): one focus-stacked image from a single focus-pull video
- [Tessera](https://github.com/Camponotus-vagus/Tessera): macOS app for panoramas and mosaics that shows how the photos match before stitching
- [glb-print-prep](https://github.com/Camponotus-vagus/glb-print-prep): repairs compressed GLB files and cuts their triangle count for 3D printing

### Utilities

- [pcloud-safe-copier](https://github.com/Camponotus-vagus/pcloud-safe-copier): file-by-file copies to FUSE-mounted cloud drives that don't freeze halfway
- [Surya-OCR-PRO](https://github.com/Camponotus-vagus/Surya-OCR-PRO): document OCR with layout analysis, CLI and GUI
